# NexusTech Enterprise - Landing Page

Landing page moderna de alta conversión para soluciones de infraestructura TI, equipamiento de cómputo empresarial y servicios gestionados 24/7 (NOC/SOC).

## Estilo y Diseño
- **Paleta de Colores**: Minimalista monocromática (blanco y tonos de gris sobre fondo oscuro profundo `#0A0A0A`).
- **Framework CSS**: Tailwind CSS (vía CDN con configuración personalizada de tokens de diseño).
- **Tipografía**: Plus Jakarta Sans (encabezados), Inter (cuerpo), JetBrains Mono (código y telemetría).
- **Iconografía**: Google Material Symbols Outlined.

## Estructura del Proyecto
- `index.html` / `code.html`: Archivo principal de la landing page con todos los componentes interactivos.
- `DESIGN.md`: Especificaciones del sistema de diseño, tokens de color, componentes y reglas visuales.
- `screen.png`: Captura de pantalla de la interfaz.

## Despliegue
Este proyecto puede ser desplegado de forma estática en cualquier servidor web (Apache/XAMPP, Nginx) o plataformas como GitHub Pages, Vercel o Netlify.
